# 🤖 Мультиагентная система с интеллектуальным мониторингом ошибок

## 🎯 Обзор

Создана полнофункциональная мультиагентная система, которая выполняет сложные многоуровневые задачи через цепочку специализированных агентов. Главный оркестратор координирует работу агентов, оценивает качество результатов и автоматически исправляет ошибки на основе правил из банка знаний.

## ✅ Ключевые достижения

### 🏗️ Архитектура системы
- **Главный оркестратор** с интеллектуальным управлением workflow
- **StateManager** для управления состоянием и механизмами отката
- **Система качества** с автоматической оценкой каждого этапа
- **7 специализированных агентов** выполняющих последовательно задачи

### 🧠 Умный банк знаний
- **systemPatterns.md** - паттерны мониторинга и исправления ошибок
- **base_rule_1.md** - правила автоматического исправления ошибок
- **Quality Assurance Loop** - периодическое обновление документации
- **Правила РАБОТАЮТ на практике** - доказано реальным исправлением ошибок

## 🔄 Агенты системы

### 1. 🔍 ResearchAgent
- Поиск и анализ информации из интернет-источников
- Сбор фактических данных и источников
- Формирование исследовательской базы

### 2. 📝 ExplanationAgent  
- Расширенное объяснение найденной информации
- Создание доступных концепций и примеров
- Адаптация под целевую аудиторию

### 3. 🔗 SynthesisAgent
- Объединение данных от предыдущих агентов
- Выявление связей и закономерностей
- Создание целостной картины

### 4. 🎯 PresentationAgent
- Создание презентации на 1 минуту (4-5 слайдов)
- Структурирование информации для эффективной подачи
- Расчет времени выступления

### 5. 🖼️ ImageGeneratorAgent
- Генерация изображений для каждого слайда презентации
- Создание визуального контента на основе текста
- Классификация слайдов для выбора подходящих изображений
- Сохранение изображений в различных форматах

### 6. 🎵 AudioAgent
- Создание аудиодорожки для презентации
- Генерация голосового сопровождения для слайдов
- Синтез речи из текста с естественным звучанием
- Создание временных меток для синхронизации

### 7. 🎬 VideoAgent
- Создание видеофайла из изображений слайдов
- Наложение аудиодорожки на видео
- Синхронизация изображений с голосом
- Добавление переходов и визуальных эффектов

## 🚀 Быстрый старт

### Установка и запуск
```bash
# Клонирование репозитория
git clone <repository-url>
cd MultiAgentProjct

# Создание виртуального окружения
python3 -m venv venv_multiagent_py311

# Установка зависимостей
pip install -r requirements.txt

# Запуск системы
python test_real_agents.py
```

### Пример использования
```python
from src.orchestrator import Orchestrator
from src.agents import ResearchAgent, ExplanationAgent, SynthesisAgent, PresentationAgent

# Создание оркестратора
orchestrator = Orchestrator()

# Регистрация агентов
orchestrator.register_agent(AgentStep.RESEARCH, ResearchAgent())
orchestrator.register_agent(AgentStep.EXPLANATION, ExplanationAgent())
orchestrator.register_agent(AgentStep.SYNTHESIS, SynthesisAgent())
orchestrator.register_agent(AgentStep.PRESENTATION, PresentationAgent())

# Выполнение workflow
result = await orchestrator.execute_workflow({
    "topic": "Искусственный интеллект в медицине",
    "requirements": "Создать презентацию на 1 минуту"
})

print(f"Успешность: {result.success}")
print(f"Шагов выполнено: {result.steps_completed}/{result.total_steps}")
```
